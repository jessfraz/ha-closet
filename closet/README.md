# Closet

Browse a wardrobe inventory in Home Assistant. Validate and sync a TOML catalog
with the native CLI; the app stays a read-only view. JSON catalogs also work.

Install the Closet integration through Marketplace or HACS as well as this
app. It handles discovery and adds inventory status and read-only Assist queries.

Today is an optional outfit lottery using a configured Home Assistant AI Task.
The inventory works without it.
